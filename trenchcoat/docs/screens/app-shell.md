# App Shell Inset

Collapsible sidebar with workspace, menu, projects and account – the frame every screen sits in. Its parts – Tabs (a tablist with arrow keys; optional `label`), ViewToggle (the library Segmented Control), SearchField, the toolbar tools, Dropdown / MenuButton menus (focus moves in, arrow keys, Escape and picks return focus to the trigger) and Popover (a named dialog, or `role="none"` around a menu) – use the pattern tokens; focus follows the sidebar and work area when they fold away; `collapsed`/`defaultCollapsed`/`onCollapsedChange` and `panelOpen`/`defaultPanelOpen`/`onPanelOpenChange`

- `app-shell.tsx`

One style.
